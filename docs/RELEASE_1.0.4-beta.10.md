# AgentsDock 1.0.4-beta.10

- **Show reasoning traces** now applies only while a Codex turn is running.
  Finished and stopped turns collapse into the same history view with either
  setting. Expand the activity history to read retained summaries and supplied
  reasoning text.
- Hidden reasoning no longer splits adjacent commands into repeated
  **Ran commands** rows. Expanding reasoning preserves its original position
  between commands and commentary.
- Clarify the setting's behavior in English and Chinese.

These presentation fixes work with the existing server contract.
