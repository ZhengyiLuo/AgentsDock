# AgentsDock 1.0.7-beta.6

Draft release notes — candidate validation is not complete; not published.

- Add OpenCode chats, model selection, permissions, attachments and local skills
  with the matching AgentsServer beta and OpenCode CLI 1.18.29.
- Retain native Claude Goals, compact thinking, saved scroll positions and
  faster reconnects when switching chats from the previous beta candidates.
- Keep desktop updates independent of the server's version and update channel.

OpenCode requires provider setup on the server. Live steering, native goals,
forks, side chats and external-history import are not supported for OpenCode.
Permission/workspace changes start fresh native context while preserving the
visible timeline. This is a direct Electron beta, not a TestFlight release.

Windows installers follow the existing unsigned-preview policy.
