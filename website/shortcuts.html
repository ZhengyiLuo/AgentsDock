Keyboard shortcuts

Every keyboard shortcut in the AgentsDock desktop app, for Mac, Windows, and Linux.

General

ActionMacWindows / Linux
New chat⌘NCtrlN
Open workspace file⌘OCtrlO
Attach files⇧⌘OCtrlShiftO
Settings⌘,Ctrl,
Find chat⌘PCtrlP
Find in chat⌘FCtrlF
Close⌘WCtrlW

Navigation

ActionMacWindows / Linux
Next workspace tab⌃⇥CtrlTab
Previous workspace tab⌃⇧⇥CtrlShiftTab
Focus left chat pane⌥⌘←CtrlAlt←
Focus right chat pane⌥⌘→CtrlAlt→
Next server⇧⌘]CtrlShift]
Previous server⇧⌘[CtrlShift[
Toggle inspector⌘LCtrlL
Jump to latest⌘↓Ctrl↓

Terminal

ActionMacWindows / Linux
Toggle terminal⌃`Ctrl`
New tmux window⌘TCtrlT
Split pane right⌘DCtrlD
Split pane down⇧⌘DCtrlShiftD
Find in terminal⌘FCtrlF

Messaging

ActionMacWindows / Linux
Send message↩Enter
Steer now (queue while running)⌘↩CtrlEnter

Standard system shortcuts (cut, copy, paste, undo, select all) work as usual. On Windows and Linux, ⌘ maps to Ctrl.
