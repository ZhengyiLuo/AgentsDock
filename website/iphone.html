Client install

Install AgentsDock on any supported client device, then connect it to your AgentsServer. The client is your window into the server; chats and agent work run on the remote machine you set up.

1Mac desktop app

Download the macOS .dmg, open it, and move AgentsDock to Applications if prompted. Then open AgentsDock from Applications or Launchpad.

Download for macOS →

Requires macOS 14 or later. The current desktop build is universal for Apple silicon and Intel Macs.

2Windows desktop app

Download the Windows .exe installer, run it, then open AgentsDock after installation finishes.

Download for Windows →

Requires Windows 10 or later on x64.

3Linux desktop app

Download the AppImage for your machine, make it executable if your desktop does not do that automatically, then launch it.

chmod +x AgentsDock-*.AppImage
./AgentsDock-*.AppImage

Download Linux x86_64 → Download Linux ARM64 →

Use x86_64 for most Intel/AMD PCs and ARM64 for ARM Linux machines.

4iPhone & iPad

On your iPhone or iPad, download AgentsDock from the App Store and open it.

Download AgentsDock on the App Store →

Requires iOS / iPadOS 16.4 or later.

5Android

Android is currently distributed as an APK download. Open the Android release page, download the APK asset, allow installation from your browser or file manager if Android asks, then open AgentsDock.

Open the Android APK release page →

Current Android APK: AgentsDock 0.1.1 beta.7 arm64. The release page includes build details, SHA-256 checksums, and validation notes.

6Connect to your server

After installing the client, add your server address and access token. New here? Follow the Setup guide to get a server running, then start your first chat.
