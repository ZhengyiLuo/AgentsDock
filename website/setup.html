Setup guide

Quick setup guide

Last updated: July 20, 2026

AgentsDock has two halves: the app on your Mac, iPhone, or iPad, and the AgentsServer that runs the real work on a remote machine you own. This guide gets them talking to each other. Plan on about 15 minutes.

What you'll need

  • A remote machine you control — a macOS or Linux computer that stays on — with tmux installed. This runs the AgentsServer.
  • A Tailscale account, so the app can reach the server securely from anywhere.
  • Your Claude Code and/or Codex accounts, to sign the CLIs in on the server.
  • The AgentsDock app on the device you'll actually use — download it here.

AgentsDock is fully self-hosted. Your chats, files, and API keys stay on your server — the app is just a window into it.

1Put both machines on the same Tailscale network

Install Tailscale and sign in with the same account on both the remote machine and every device you'll open AgentsDock from. This is what lets your laptop or phone reach the server without opening any ports to the public internet.

Once both are logged in, note the remote machine's Tailscale address — it looks like 100.x.x.x, or you can use its Tailscale hostname. You'll need it in step 4.

2Install the AgentsServer on the remote

On the remote machine, clone the server and run its installer:

git clone https://github.com/ZhengyiLuo/AgentsServer.git
cd AgentsServer
./install.sh

The server listens on port 7850 by default. Leave it running on the remote machine — that's the piece the app connects to.

3Sign in to Claude Code and Codex on the remote

AgentsDock runs the Claude Code and Codex CLIs on your server, using your own accounts — it never proxies or sees your model requests. So the CLIs have to be installed and signed in on the remote machine, not on your phone or laptop.

On the remote, make sure each CLI you plan to use is installed and authenticated (run each one once and complete its sign-in). If a CLI isn't signed in, AgentsDock will show that backend as unavailable when you try to use it.

4Connect the app to your server

Open AgentsDock and add your server with two things:

  • Server URL — your remote's Tailscale address and the port, for example http://100.x.x.x:7850. A bare host:7850 works too; the app adds http:// for you.
  • Access token — the token your AgentsServer uses to authorize the app. Paste the same value the server is configured with. In the app you'll find this field under the server's Security section on Mac, or the server card in the sidebar on iPhone and iPad.

Save it, and you're connected. Start a chat, pick Claude Code or Codex, and point it at a working directory on your server.

Not connecting?

  • Confirm the server URL opens in a browser on the same device — if the browser can't reach it, the app can't either.
  • Check that Tailscale is active and signed in on both ends, and that you used the Tailscale address (not a local IP that only works on the server's own network).
  • Make sure the port (:7850) is included and the access token matches exactly, with no extra spaces.
