Update to the latest version

AgentsDock updates in place — from the app's settings. You choose how new versions reach you with two channels: Stable and Beta.

How to update to the latest version in the app

Open Settings and scroll to the update section. AgentsDock checks for new versions and shows what's available — click Check now, then Restart to update to install and relaunch on the latest build.

Update the app and server together

AgentsDock has two halves — the app (the client on your device) and the AgentsServer (running on your remote). Each shows its own version and its own Check and update controls in the same panel.

When you update, bring both to the latest version at the same time. Keeping the app and server on matching releases avoids version mismatches — features and fixes often land on both sides together. Use Update server to Beta / Install or update AgentsServer for the remote, and Restart to update for the app.

Stable vs. Beta

Both the app and the server have a Stable / Beta switch:

  • Stable — polished, well-tested releases. The right choice for everyday use.
  • Beta — the newest signed builds, with features and fixes before they reach Stable. Great if you want the latest, and don't mind the occasional rough edge.

Pick the same channel on both sides so the app and server stay in step. Want to know exactly what changed in each version — and which are Stable vs. Beta? Every release and its notes are on GitHub.
