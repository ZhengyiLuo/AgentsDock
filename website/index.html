How it works

Up and running in three steps.

  1. 01
    Download the app

    Install AgentsDock on macOS or Linux — it's the control surface, not the compute.

  2. 02
    Connect your server

    Run AgentsServer on a machine you control, then add its URL and access token in the app.

  3. 03
    Continue from any connected client

    Runs, files, and chats stay together on your server, so every connected client sees the same workspace.

Supported agents

Bring your own CLI. Keep control of your credentials.

AgentsDock connects to Claude Code and Codex running on your server — the same CLIs you already have authenticated. API keys stay on that machine, and AgentsDock does not proxy or resell model access.

Claude Code

Anthropic's agentic CLI. Run it authenticated with your own API key — AgentsDock streams the events.

Codex CLI

OpenAI's coding agent. Point it at your OpenAI key and working directory — same deal, your credentials, your compute.

Everything you need

Built for researchers.

01

Rich media, streamed back

Videos, simulation results, and image grids land directly in chat — no digging through folders or pulling files manually.

02

One workspace, every client

Runs, files, and chats stay together on your server, so connected clients share the same workspace.

03

Terminal that survives everything

Each chat has a persistent tmux session on your server. Close the app, come back hours later — the process is still running.

04

Agents that hand off to each other

Digest mode lets one agent summarize its work and pass context to the next — no copy-pasting, no manual handoffs.

05

Fully self-hosted

AgentsServer runs on infrastructure you control. Claude and Codex communicate according to the provider settings you choose.

06

Claude + Codex, your choice

Choose the right backend, model, and reasoning level for each chat without splitting your work across apps.
