How it works

Up and running in four steps.

  1. 01
    Download the app

    Install AgentsDock on your Mac or iPhone — it's the control surface, not the compute.

  2. 02
    Set up your server in one push

    Run the deploy script on any machine you own. It installs the server, Claude CLI, and Codex CLI — then paste the URL into the app and you're live.

  3. 03
    Work from anywhere, in sync

    Start a job on Mac, check progress from your phone, review results on iPad. Every run, file, and chat stays in the same place across all your devices.

Supported agents

Bring your own CLI. We don't touch your tokens.

AgentsDock connects to Claude Code and Codex running locally on your server — the same CLIs you already have authenticated. Your API keys stay on your machine. We never proxy, resell, or see your model requests.

Claude Code

Anthropic's agentic CLI. Run it authenticated with your own API key — AgentsDock streams the events.

Codex CLI

OpenAI's coding agent. Point it at your OpenAI key and working directory — same deal, your credentials, your compute.

Everything you need

Built for researchers.

01

Rich media, streamed back

Videos, simulation results, and image grids land directly in chat — no digging through folders or pulling files manually.

02

One workspace, every device

Start a run on your Mac, monitor it from your phone, review results on iPad. Everything is in sync, always.

03

Terminal that survives everything

Each chat has a persistent tmux session on your server. Close the app, come back hours later — the process is still running.

04

Agents that hand off to each other

Digest mode lets one agent summarize its work and pass context to the next — no copy-pasting, no manual handoffs.

05

Fully self-hosted

Run everything on your own server or cluster. Your code, credentials, and outputs never leave infrastructure you control.

06

Claude + Codex, your choice

Choose the right backend, model, and reasoning level for each chat without splitting your work across apps.

Desktop preview

Bring your agents into the Dock.

Install the desktop client, connect it to your AgentsDock server, and keep Claude and Codex available from every machine you use.
