How it works

Up and running in three steps.

  1. 01
    Download the app

    Install AgentsDock on macOS or Linux — it's the control surface, not the compute.

  2. 02
    Connect your server

    Run AgentsServer on a machine you control, then add its URL and access token in the app.

  3. 03
    Continue from any connected client

    Runs, files, and chats stay together on your server, so every connected client sees the same workspace.

Supported agents

Bring your own CLI. Keep control of your credentials.

AgentsDock connects to Claude Code and Codex running on your server — the same CLIs you already have authenticated. API keys stay on that machine, and AgentsDock does not proxy or resell model access.

Claude Code

Anthropic's agentic CLI. Run it authenticated with your own API key — AgentsDock streams the events.

Codex CLI

OpenAI's coding agent. Point it at your OpenAI key and working directory — same deal, your credentials, your compute.

Quick start

Stand up your server in three commands.

Clone the server, run the idempotent installer, then paste the URL into the app. It installs the versioned runtime plus the Claude and Codex CLIs — your chat state lives under ~/.agentsdock, on infrastructure you control.

Read the full setup guide ↗
bash
# 1 · Install the AgentsDock server
$ git clone https://github.com/ZhengyiLuo/AgentsServer.git
$ cd AgentsServer
$ ./install.sh

# 2 · Launch the app and paste your server URL
$ open -a AgentsDock
