Key features

What AgentsDock gives you once you're connected — the same across desktop and mobile.

01

Full terminal access from any device

Attach to your chat's persistent tmux session from any device — the same shell on desktop and mobile.

02

Agent-to-agent messaging

Bring another agent into the chat with @ and hand it a task — it works on its side and replies back.

Start an agent-to-agent chat

Type @, pick the chat you want to reach, and send. A mention chip marks who you're addressing — it works across chats, and even across servers.

How it works

Your message is delivered as a tracked exchange. The other agent works on it on its own machine and replies straight back into your chat, with the hand-off kept visible — who was addressed, whether a reply is expected, and when it expires.

That first message also opens a lasting connection: in the @ picker the chat goes from Will grant Send + Ask when sent to Granted · Send + Ask, so you can keep messaging that agent without granting access again.

Revoke access

Open the @ picker and click Revoke next to a connected chat. That closes the connection until you @ it again. Each chat holds a limited number of connections, so revoke the ones you no longer need.

03

Scheduled jobs

Queue interval and recurring jobs so long-running work runs on time, unattended.

04

View and edit your code

Browse, preview, and edit files on your remote directly from the app.

The files you can open are the ones under the chat's working directory — the folder on your remote that this chat's agent works in. Set it when you create the chat, or change it anytime from the Session panel on the right.

05

Resume other chats

Bring a Claude Code or Codex chat you started outside AgentsDock into the app, with its full history and context. There are two ways to do it.

We recommend you import directly.

Import directly

Open Import chat from the / menu to see every Claude Code and Codex session on that machine — each one listed with a preview and timestamp. Tick the chats you want and hit Import, and they land in AgentsDock with their full history — including conversations you ran entirely outside the app.

Import using Resume ID

Every Claude Code or Codex session has a session ID — its resume ID. Choose Resume by session ID, paste the ID in, and AgentsDock resumes that conversation in the app, full history and context intact, so you can carry it on from any device. It works for chats you began outside AgentsDock, not just ones started in the app.

06

Slash commands

Type / in the message box to pull up everything you can do in a chat — commands and skills, in one quick menu.

Press / and a palette opens right above the message box: attach files, reference another chat, send feedback, switch the model, manage MCP servers, start a new chat, and more. Use the arrow keys to move, Enter to run, Esc to close.

We support a focused set of slash commands today, with more skills on the way — the menu keeps growing, so it's worth checking what / offers.

07

Fork any chat

Branch any chat with one click to try a new direction — the original stays intact.

Want to explore a different approach without losing your current thread? Fork the chat, and AgentsDock copies its full history into a new branch you can take anywhere — while the original stays exactly as it was. It's ideal for trying an alternative prompt, running an ablation, or testing a risky change side by side with the version that already works.
