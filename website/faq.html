Frequently asked questions

Common questions about AgentsDock — click a question to expand the answer. Can't find yours? Ask us and we'll add it here.

Why can't I see the latest Codex or Claude models in AgentsDock?

AgentsDock talks to the agent runtimes installed on the machine that runs your AgentsServer. The model list in the app comes from the Codex and Claude Code CLIs on that machine, so updating the AgentsDock app on your phone or laptop does not add new models.

How to get the latest models

  1. On the machine that runs AgentsServer (not the device you're connecting from), update the provider CLI: 
    # Codex
codex update
codex --version

# Claude Code
claude update
claude --version
  2. Back in AgentsDock, open Settings and click Recheck CLIs to refresh the model list. No server restart is needed.
  3. Still missing? Check that you're connected to the server you just updated, then check the provider side: your account or plan, your workspace's admin settings, and whether the model has rolled out to you yet. Updating the CLI makes a model visible; it doesn't grant access to it.

If you run more than one server, repeat the update on each — every server keeps its own CLIs.

Which platforms does AgentsDock run on?

The client runs on macOS, Windows, Linux, iPhone, iPad, and Android. The server side, AgentsServer, runs on macOS (Apple silicon) or Linux. See the client install guide for each platform.

Does AgentsDock see my code, prompts, or model requests?

No. AgentsDock runs the Claude Code, Codex, and Cursor CLIs on your own machine, with your own accounts. It never proxies your model requests. Optional, anonymous usage analytics are off by default and can be turned on in Settings. Details are in the privacy policy.

Do I need Tailscale?

Only to reach your server from outside its local network. On the same Wi-Fi you can use the machine's local IP address. Tailscale gives the server a private 100.x.x.x address you can reach from anywhere without opening ports. See the setup guide.

Can I connect to more than one server?

Yes. Add each server from the server menu at the top of the sidebar with Add Server, then switch between them any time. Each server keeps its own chats.

Where do I find my access token?

The installer prints it once when it finishes. To show it again, run this on the server machine:

./install.sh --show-token

Paste it into the Access token field when adding the server in the app.

Can I resume a chat I started outside AgentsDock?

Yes. Open Import chat from the / menu to pick from every Claude Code or Codex session on that machine, or choose Resume by session ID and paste the ID. Either way the full history comes with it. See Resume other chats.

How do I update AgentsDock and the server?

Both update from the app's Settings: click Check now, then Restart to update. The app and the server each have their own Stable / Beta switch. See Updates.

Is AgentsDock open source?

Yes. The client is on GitHub and the server is at AgentsServer. Stars are welcome.
