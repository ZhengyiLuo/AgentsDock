常见问题

关于 AgentsDock 的常见问题，点击问题展开答案。没找到？告诉我们，我们会补充到这里。

为什么在 AgentsDock 里看不到最新的 Codex 或 Claude 模型？

AgentsDock 连接的是运行 AgentsServer 那台机器上的 agent runtime。应用里的模型列表来自那台机器上的 Codex 和 Claude Code CLI，所以更新手机或电脑上的 AgentsDock 应用并不会带来新模型。

如何获取最新模型

  1. 在运行 AgentsServer 的那台机器上（不是你正在用来连接的设备）更新对应的 provider CLI： 
    # Codex
codex update
codex --version

# Claude Code
claude update
claude --version
  2. 回到 AgentsDock，打开设置（Settings），点击 Recheck CLIs 刷新模型列表。不需要重启服务器。
  3. 还是没有？先确认你连接的就是刚更新的那台服务器，再检查 provider 那边：你的账号或套餐、workspace 的管理员设置，以及该模型是否已经向你开放。更新 CLI 只是让模型可见，并不等于获得使用权限。

如果你有多台服务器，每台都要更新一次——每台服务器有自己独立的 CLI。

AgentsDock 支持哪些平台？

客户端支持 macOS、Windows、Linux、iPhone、iPad 和 Android。服务器端 AgentsServer 运行在 macOS（Apple 芯片）或 Linux 上。各平台的安装方法见客户端安装。

AgentsDock 会看到我的代码、提示词或模型请求吗？

不会。AgentsDock 在你自己的机器上、用你自己的账号运行 Claude Code、Codex 和 Cursor 的 CLI，从不代理你的模型请求。匿名使用统计默认关闭，可在设置中开启。详情见隐私政策。

我需要 Tailscale 吗？

只有在局域网之外访问服务器时才需要。在同一 Wi-Fi 下可以直接用机器的局域网 IP。Tailscale 会给服务器分配一个私有的 100.x.x.x 地址，无需开放端口就能从任何地方访问。见搭建指南。

可以连接多台服务器吗？

可以。在侧边栏顶部的服务器菜单里用 Add Server 逐个添加，之后随时切换。每台服务器保留自己的会话。

访问令牌在哪里找？

安装脚本结束时会打印一次。想再次查看，在服务器机器上运行：

./install.sh --show-token

在应用里添加服务器时，把它粘贴到访问令牌（Access token）一栏。

可以恢复在 AgentsDock 之外开始的会话吗？

可以。从 / 菜单打开导入会话（Import chat），从那台机器上所有的 Claude Code 或 Codex 会话里挑选；或者选择按会话 ID 恢复（Resume by session ID）并粘贴 ID。两种方式都会带上完整历史。见恢复其他会话。

怎么更新 AgentsDock 和服务器？

两者都在应用的设置里更新：点 Check now，再点 Restart to update。应用和服务器各有自己的 Stable / Beta 开关。见更新。

AgentsDock 开源吗？

开源。客户端在 GitHub，服务器端在 AgentsServer。欢迎点个 star。
