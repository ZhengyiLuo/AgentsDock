功能指南

每个功能都有自己的页面；这里按工作方式分组，方便你先选方向，再进入具体操作。

会话

会话与协作

把会话本身当作协作入口：交给另一个 agent 处理、分享给其他人、从当前上下文开一个分支，或用 Side chat 问一个不打断主线的小问题。

01 Agent 之间通话 用 @ 把另一个会话拉进来，让另一个 agent 接手一段工作。 02 用链接和 token 分享会话 生成受保护的浏览器页面，要求 token 访问，并且可以随时撤销。 03 Side chat 侧聊 围绕当前上下文快速追问，但不打断主会话。 04 Fork 任意会话 把完整历史复制到一个新分支，用来尝试另一条路线。 05 恢复其他会话 导入或恢复在 AgentsDock 之外开始的 Claude Code / Codex 会话。

工作区

在远程机器上工作

真正的工作发生在你的服务器上；桌面和移动客户端只是窗口，让你从任何设备访问终端、文件和工作目录设置。

06 从任何设备完整访问终端 在桌面、iPhone、iPad 或其他客户端打开同一个持久 shell。 07 查看与编辑你的代码 在应用里浏览和编辑当前会话工作目录下的文件。

自动化

更快操作，并安排之后的工作

在会话中用快捷命令快速执行操作；需要稍后运行的事情，则交给定时任务，即使不一直开着应用也能继续。

08 斜杠命令 用一个快捷菜单打开附件、引用会话、反馈、切换模型等操作。 09 定时任务 把之后要做或需要重复执行的工作交给服务器运行。
