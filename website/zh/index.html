工作原理

  • 1用几条简单命令搭建你的服务器
  • 2从任何设备访问这台服务器
  • 3让 agent 替你做研究和模型训练
阅读完整搭建指南 →

支持：

  • Claude Code
  • Codex
  • Cursor
  • Tailscale （可选）
  • tmux （可选）
bash
# 1 · 安装 AgentsDock 服务器
$ git clone https://github.com/ZhengyiLuo/AgentsServer.git
$ cd AgentsServer
$ ./install.sh

# 2 · 打开应用，粘贴你的服务器地址
$ open -a AgentsDock

💻 为 AI 研究者而生

所有 agent，并排使用

在一个地方并排和不同的 agent 聊天——Claude Code、Codex，还有更多。

从任何设备连接多台服务器

实验室的工作站、家里的 Mac mini、租来的 GPU 机器——全部连上，随时切换，在你的每一台设备上都行。

查看和编辑代码

直接打开、编辑远程机器上的文件，自带语法高亮——不需要另外的编辑器。

随时随地完整访问终端

从任何设备接入会话的持久 tmux 会话——同一个 shell，处处可用。

查看视频任务结果

agent 会把图表、图片和渲染好的 rollout 直接发回聊天里——在会话中就能审阅一次运行的真实输出。
