反馈问题

遇到 bug，或者有功能建议？问题都在 GitHub 上——而最快的入口就在会话里。

在会话中发送反馈

在输入框输入 /feedback——或从 / 菜单选择发送反馈（Send feedback）。它会直接带你到 GitHub 上的 AgentsDock 问题表单，不用去找仓库。

在 GitHub 上打开 AgentsDock 问题表单 →

……或直接在 GitHub 上提交问题

目的地相同，如果你更愿意直接过去的话。在 AgentsDock 发布仓库新建一个 issue，写清标题和描述——复现步骤、你期望的结果、实际发生了什么——能附上截图或录屏更好。这对我们定位问题非常有帮助。

在 GitHub 上新建 issue →

建议先快速翻一下已有的 issue——也许已经有人报告过了。

有简短的问题，或者拿不准某个现象算不算 bug？欢迎来社区打个招呼。我们很活跃，乐意帮忙。
