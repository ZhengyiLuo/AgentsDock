键盘快捷键

AgentsDock 桌面应用的全部键盘快捷键，涵盖 Mac、Windows 和 Linux。

通用

操作MacWindows / Linux
新建会话⌘NCtrlN
打开工作区文件⌘OCtrlO
附加文件⇧⌘OCtrlShiftO
设置⌘,Ctrl,
查找会话⌘PCtrlP
在会话中查找⌘FCtrlF
关闭⌘WCtrlW

导航

操作MacWindows / Linux
下一个工作区标签页⌃⇥CtrlTab
上一个工作区标签页⌃⇧⇥CtrlShiftTab
聚焦左侧会话面板⌥⌘←CtrlAlt←
聚焦右侧会话面板⌥⌘→CtrlAlt→
下一个服务器⇧⌘]CtrlShift]
上一个服务器⇧⌘[CtrlShift[
切换检查器⌘LCtrlL
跳到最新⌘↓Ctrl↓

终端

操作MacWindows / Linux
切换终端⌃`Ctrl`
新建 tmux 窗口⌘TCtrlT
向右拆分面板⌘DCtrlD
向下拆分面板⇧⌘DCtrlShiftD
在终端中查找⌘FCtrlF

消息

操作MacWindows / Linux
发送消息↩Enter
立即引导（运行中排队）⌘↩CtrlEnter

系统标准快捷键（剪切、复制、粘贴、撤销、全选）照常可用。在 Windows 和 Linux 上，⌘ 对应 Ctrl。
