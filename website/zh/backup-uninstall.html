备份、恢复与卸载

AgentsServer 把所有东西都以普通目录的形式存放在你的机器上。本页说明各项内容的位置、如何备份和恢复，以及卸载时到底删除什么、保留什么。

适用于 AgentsServer 1.0.x。命名实例路径和名称释放备份需要多服务器中描述的 main 分支构建。

什么存在哪里

  • 状态——会话及其事件历史、定时任务、上传和生成的文件、安全对等凭据、终端元数据：~/.agentsdock（默认服务器）· ~/.agentsdock-instances/NAME（命名实例）
  • 配置——访问令牌和服务设置：~/.config/agents-server · ~/.config/agents-server-instances/NAME
  • 运行时——已安装的发布版本及其 Python 环境（完全可重装，不含个人数据）：~/.local/share/agents-server · ~/.local/share/agents-server-instances/NAME
  • 日志——~/Library/Logs/AgentsServer/（macOS）或用户日志（Linux）

你的 Claude Code 和 Codex 会话本身存放在这些工具自己的目录里（~/.claude、~/.codex），项目文件则在你自己存放的位置——AgentsServer 只引用它们，并不拥有它们。

备份

只有状态和配置目录重要；运行时可以重装。先停止服务器，避免复制过程中文件发生变化：

# macOS
launchctl bootout gui/$(id -u)/com.agentsdock.server
# Linux
systemctl --user stop agents-server.service

cp -a ~/.agentsdock ~/agentsdock-backup-$(date +%F)
cp -a ~/.config/agents-server ~/agentsdock-config-backup-$(date +%F)

# then start it again
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.agentsdock.server.plist   # macOS
systemctl --user start agents-server.service                                           # Linux

对于命名实例，请使用它自己的服务名和每个实例的位置中列出的 …-instances/NAME 路径。配置备份包含你的访问令牌——请存放在私密的地方。

恢复

原位状态会被自动接管。如果状态目录还在（正常卸载后就是如此），只需再次运行 ./install.sh 就能重新连上同样的会话、任务和文件。除非配置目录也保留了，否则重装会生成新的访问令牌——若是这样，请在应用里更新令牌。

从你自己做的备份恢复：停止服务器，把备份的目录放回原来的路径，再启动它（或运行 ./install.sh）。想保留旧令牌的话，把配置目录也一并恢复。

重装不会自动恢复名称释放备份——那部分在下文单独说明。

卸载

./uninstall.sh                          # lists instances, confirms exact names
./uninstall.sh --instance work          # one named instance
./uninstall.sh --all                    # everything
./uninstall.sh --all --exclude default  # all named instances, keep default
./uninstall.sh --yes                    # skip the prompt (default server)

卸载会移除用户服务、版本化的运行时，以及包括访问令牌在内的生成配置。它会保留状态目录下的会话历史、任务、文件、安全对等凭据和终端，之后再运行 ./install.sh 会接管同样的历史。它从不使用包管理器或 sudo，并拒绝对根目录、主目录、宽泛的系统目录或相互重叠的路径进行操作。

名称释放备份

当一个命名实例的名称被释放时（移除它，或用同一名称创建新实例），它的状态目录不会被删除——而是移到一个私有备份：

~/.config/agents-server-manager/history-backups/<name>-<random>/state

默认实例的名称永远不会被释放。原始的 Claude/Codex 会话和你的项目文件不受影响；只有 AgentsDock 自有的内容会移入备份。

释放名称会把它保存的 AgentsDock 数据保留在命令打印的私有备份位置。重装该实例不会自动恢复那个备份，重装后的实例从空的会话列表开始。目前还没有内置的恢复命令——请保持备份原样（不要移动或合并它，尤其是在该名称已被重新使用的情况下），并到 Discord 或通过反馈问题寻求恢复指引。

清除状态

./uninstall.sh --purge-state

这是唯一的破坏性选项。它会永久删除状态目录——会话历史、任务、文件、令牌、安全对等凭据。它总是要求你输入完整的状态路径确认，--yes 永远无法跳过这个提示。

终端会话

卸载后，持久会话终端仍会继续运行。它们是普通的 tmux 会话，按服务器隔离：

tmux ls                          # default server: sessions named zd_*
tmux -L agents-server-NAME ls    # named instance: sessions named zdi_NAME_*

只关闭你确认属于所移除服务器的 AgentsDock 会话终端。机器上的其他 tmux 会话以及其他实例的会话是独立的，不受影响。
